01 / AI PRODUCTIVITY TOOL

素材管理，
变成工具。

面对分散的主图、A+、场景图和尺寸图，不再依赖硬盘层级逐层查找，而是按用途、编码、款号与标签重新组织。

Problem
文件量持续增加，命名和路径不足以支撑快速检索与复用。
Build
把筛选、分类、预览与复用动作整合进同一套界面。
Value
让素材从“存在哪里”转向“现在要怎么用”。
02 / PROMPT PLUGIN

Prompt 与规则，
封装成入口。

为 AI 图像、视频与电商工作流建立本地 Prompt 收录插件，让品牌经验、参数和禁用项一起被保存和调用。

Capture
收录 Prompt、用途、模型、参考与版本信息。
Route
用分类和标签把请求导向正确模板，而不是重新从零编写。
Reuse
把个人提示词收藏变成团队可检索、可追踪的生产入口。
03 / WORKFLOW BRIDGE

图像工作流，
连接生产节点。

用 Codex 接收设计意图、拆解修改位置与执行步骤，再交给图像工具完成生成，让“想改哪里”能够被准确执行和复盘。

Input
设计师描述目标、问题位置和必须保持不变的内容。
Translate
Codex 将自然语言整理为工具可执行的任务和规则。
Output
结果、版本与修改记录留在同一条生产链路中。
