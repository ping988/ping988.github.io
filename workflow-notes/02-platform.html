通铺平台主图工作流

案例与工作流说明 · 配套源码保存在 GitHub 私人仓库。以下是已有规则与作品的整理，不是新批次的实测报告。

工作流定位

从单张制作，转为有信息分工的整套生产。

减少逐张规划和重复设计，统一一套图片的卖点、字体、场景与细节表达。

我的贡献

将项目中的设计判断沉淀为 Skill 规则，组织产品资料、任务清单与参考案例；建立检查标准，在关键节点审核并把控最终视觉质量。具体项目的职责范围以对应执行记录为准。

输入与交付

输入：产品实拍、已核实卖点、平台、交付数量与参考案例。

交付：套图计划、图位设计、成套图片与交付检查。

批量组织：以 SKU × 图位组织生产；复用规则，不机械复制同一构图。

这里的批量指按清单组织多项任务，不等同于模型一次出完整套图、无限并发或全程无需人工。

执行流程

1. 核实产品、平台、参数与交付范围。
2. 按图片信息任务规划套图；当前 Skill 默认 12 图，实际数量以项目约定为准。
3. 匹配新平台案例，确定视觉规则与图位版式。
4. 按清单生成商品展示、场景、卖点、细节和尺寸等图片。
5. 逐图核验并检查整套重复、缺图及风格偏差，按产品整理交付。

质量控制与人工节点

维持商品真实性、图位职责和统一视觉。尺寸需有证据；新平台规则不直接套给亚马逊主附图或 A+。
