亚马逊 A+ 图工作流

案例与工作流说明 · 配套源码保存在 GitHub 私人仓库。以下是已有规则与作品的整理，不是新批次的实测报告。

查看 GitHub 项目、Skill 与案例归档 ↗（需授权）

工作流定位

把产品信息组织成连贯页面，而不是孤立的模块。

统一模块之间的字体、留白、场景和阅读顺序，减少重复排版及多端表达割裂。

我的贡献

将项目中的设计判断沉淀为 Skill 规则，组织产品资料、任务清单与参考案例；建立检查标准，在关键节点审核并把控最终视觉质量。具体项目的职责范围以对应执行记录为准。

输入与交付

输入：商品实拍、确认文案、同类模块参考、目标端规格。

交付：A+ 模块、完整页面及移动端适配内容。

批量组织：按 SKU × 模块 × 端别组织任务，先锁定产品，再统一整套视觉。

这里的批量指按清单组织多项任务，不等同于模型一次出完整套图、无限并发或全程无需人工。

执行流程

1. 确认产品、文案、端别与模块范围。
2. 规划页面阅读顺序，为每个模块分配明确的信息任务。
3. 将当前产品实拍与适合的模块案例配对，区分商品证据与版式参考。
4. 按模块生成并核对产品结构、图文占比和排版连续性。
5. 检查整页节奏；按需求独立安排移动端，而非仅缩小 PC 图。

质量控制与人工节点

不复用案例中的产品事实、认证或未经确认的装饰。PC 与移动端分别检查文字可读性、裁切与商品细节。

已有成果与证据状态

现有作品集收录 13 套 A+ 完整长页，包含兔子摇铃、木质音乐台、兔子安抚巾等。完整长页是已有作品，不自动证明所有案例均由同一最新版 Skill 生成；App 对照与执行记录待补。
