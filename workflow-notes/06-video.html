产品展示视频生成工作流

案例与工作流说明 · 配套源码保存在 GitHub 私人仓库。以下是已有规则与作品的整理，不是新批次的实测报告。

查看 GitHub 项目、Skill 与案例归档 ↗（需授权）

工作流定位

从商品实拍、分镜到成片，按产品组织制作。

减少镜头间商品变款、场景漂移和素材难追溯，让视频内容围绕真实产品展开。

我的贡献

将项目中的设计判断沉淀为 Skill 规则，组织产品资料、任务清单与参考案例；建立检查标准，在关键节点审核并把控最终视觉质量。具体项目的职责范围以对应执行记录为准。

输入与交付

输入：商品实拍、认可场景、视频需求与已授权制作范围。

交付：独立分镜、整合提示词、成片与生成核验记录。

批量组织：以 SKU × 视频任务组织脚本与素材映射，按授权批次推进生成。

这里的批量指按清单组织多项任务，不等同于模型一次出完整套图、无限并发或全程无需人工。

执行流程

1. 核实商品与配件，记录外形、颜色、材质和连接等不变量。
2. 复用认可场景，按展示任务策划脚本与独立分镜。
3. 逐镜核验后编写一个整合式视频提示词，明确时间与参考图号。
4. 在已授权数量、模型和费用范围内执行生成，状态不明时先查任务而非重复提交。
5. 下载并检查成片、关键帧和产品连续性，保存回执、分镜与最终版本。

质量控制与人工节点

策划或分镜不等于已生成视频。关键产品错误需处理；收费重试与模型变更不能自动扩大授权。

已有成果与证据状态

现有作品集包含床铃、小熊布书、化妆包等产品视频，以及其他 AI 影像探索。它们可作为已有成片参考，具体 fenjing-skill 批次和版本归属仍待核对。
